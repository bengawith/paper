# Robust V2 — last scientific additions

This file is deliberately short. **The manuscript and its supplementary comparison are the working drafts; this is not a parallel study plan.** All numerical data and model weights are frozen. No numerical experiment needs to be repeated before reviewing the paper.

The completed evidence includes 106,931 exact-CST XFOIL training/calibration/test observations; five properly stopped frozen ensemble members; the protected historical test; 200 before-label sealed numerical confirmation shapes (17,968/22,600 observed); ten complete NSGA-II robust seeds at 128 × 200 × 64 and ten complete nominal seeds; 2,048 fresh sensitivity scenarios; every one of the 819 strict selected XFOIL attempts (290 usable, 529 not usable); NeuralFoil comparisons against all 17,968 observed confirmation states; and 40 independently generated NACA-style source shapes separated geometrically from the original corpus (4,331/4,520 observed). No original failed case was imputed, omitted or reclassified.

**Scientific positioning:** this is a reproducible and failure-aware evaluation methodology for geometry-consistent aerofoil surrogate optimisation. NeuralFoil achieves lower numerical errors and a better XFOIL-missingness ranking in the measured comparison; neither general-purpose superiority nor a new neural architecture is claimed. The new NACA-style shape trial is source-distinct but post hoc, and NeuralFoil's internal training-shape overlap is unknown. All aerodynamic labels remain XFOIL-family numerical data, not independent CFD or experiment. The simulated perturbations are not measured manufacturing tolerances.

**The remaining independent CFD analysis:** keep the already sealed reference, risk-knee and nominal-control shapes; verify boundary conditions, Re/Mach, turbulence/transition treatment, mesh/domain/near-wall convergence and force/moment residual histories; find matching *achieved* C_L = 0.4, 0.7 and 1.0; compare drag, moment and any matched prescribed geometric deviations. Include failed cases and any ranking reversals. The existing manuscript Section 7 gives the complete protocol. The final physical aerodynamic conclusion must follow the CFD, even if it finds no robust advantage.

**Coauthor checks before journal submission:** approve exact affiliations, corresponding-author contact and CRediT roles; funding/conflict/AI disclosures; target-journal word limits and formatting; and the final native Word pagination. All 29 cited publication identities have primary-source ledgers. The current Word preview was inspected in a browser-derived layout, not Microsoft Word native page rendering.

**Simple reproduction:** on the supported Python 3.11 environment run `uv sync --extra dev --extra benchmarks --extra docs`, followed by `uv run ruff check src/robust_airfoil tests/robust_v2 scripts/robust_v2`, `uv run mypy src/robust_airfoil` and `uv run pytest -m 'not network' --run-xfoil -q`. The public tool accepts `uv run robust-airfoil predict --airfoil-file path/to/airfoil.dat --alpha-start 0 --alpha-end 8 --alpha-step 0.25`, or twelve explicit CST values using `--cst=<comma-separated values>`. It reports the exact controlled support source and frozen artifact identities. Large numerical campaigns are already frozen; do not launch them as part of normal manuscript review.
